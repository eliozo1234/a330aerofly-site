Installation

Installieren Sie die A330-300 auf PC, Android oder iOS. Wählen Sie Ihre Plattform und folgen Sie den Schritten.

PCAerofly FS 4 · Windows AndroidAerofly FS Global iOSAerofly FS Global

PC · Aerofly FS 4

  1. Öffnen Sie Ihre Gumroad Kaufbestätigung per E-Mail oder Ihre Gumroad Bibliothek und laden Sie die ZIP Datei der PC Edition herunter.
  2. Entpacken Sie sie. Sie erhalten einen Ordner namens a330.
  3. Verschieben Sie diesen Ordner nach Dokumente\Aerofly FS 4\aircraft\ (legen Sie den Ordner aircraft an, falls er fehlt).
  4. Starten Sie Aerofly FS 4. Die A330-300 erscheint in der Flugzeugliste unter Airliners.

Für ein Update laden Sie die neueste Version aus Ihrer Gumroad Bibliothek und ersetzen den Ordner a330.

Android · Aerofly FS Global

Voraussetzung: die DR400. Die Mobil Edition ersetzt die Robin DR400 in Aerofly FS Global, daher müssen Sie die DR400 in der App besitzen. Sobald die .tme Datei der A330 installiert ist, wird die DR400 durch die A330-300 ersetzt. Löschen Sie die .tme Datei der A330, um die DR400 zurückzubekommen.

Die Mobil Edition ist eine einzelne .tme Datei. Laden Sie sie aus Ihrer Kaufbestätigung oder Ihrer Gumroad Bibliothek direkt auf Ihr Smartphone oder Tablet, ohne sie zu entpacken oder umzubenennen.

Unter Android dauert die Installation mit einem Dateimanager wenige Minuten. Die Schritt für Schritt Anleitung von ZK Aviation zeigt jeden Bildschirm.

Android Anleitung öffnen

Installieren Sie die .tme Datei der A330 genau wie die Mods in der Anleitung.

iOS · Aerofly FS Global

Unter iOS werden Add ons mit 3105 in die App Daten von Aerofly FS Global kopiert. 3105 ist ein kostenloser Browser für App Daten, der außerhalb des App Store installiert wird. Zwei Teile: 3105 einmal installieren, dann die A330 Datei kopieren.

Voraussetzung: die DR400. Die Mobil Edition ersetzt die Robin DR400 in Aerofly FS Global, daher müssen Sie die DR400 in der App besitzen. Sobald die .tme Datei der A330 installiert ist, wird die DR400 durch die A330-300 ersetzt. Löschen Sie die .tme Datei der A330, um die DR400 zurückzubekommen.

3105, E-Sign und KSign sind Werkzeuge von Drittanbietern und stammen weder von Apple noch von IPACS noch von A330 Aerofly Development. Die Installation erfolgt auf eigenes Risiko.

Teil 1: die App 3105 installieren

3105 ist ein nativer Browser für iOS App Daten, der nicht im App Store erhältlich ist. Er muss daher mit einem Signierwerkzeug auf dem Gerät per Sideloading installiert werden. E-Sign und KSign sind dafür am gebräuchlichsten.

  1. Die IPA Datei von 3105 herunterladen
    • Öffnen Sie Safari und rufen Sie das offizielle GitHub Repository YangJiiii/3105 auf.
    • Öffnen Sie den Bereich Releases, scrollen Sie nach unten und laden Sie die Datei 3105-unsigned.ipa auf Ihr Gerät.
  2. Ihr Signierwerkzeug öffnen (E-Sign, KSign)
    • Starten Sie die Signier App.
    • Falls Sie noch keine haben, installieren Sie zuerst über Safari ein Signierwerkzeug und vertrauen Sie dessen Unternehmenszertifikat in den iOS Einstellungen.
  3. Die IPA importieren und signieren
    • Tippen Sie in der Signier App auf das Symbol + (Plus) oder Importieren.
    • Wählen Sie 3105-unsigned.ipa in der App Dateien.
    • Tippen Sie auf die importierte Datei, wählen Sie Signature oder Sign App und dann Ihr aktives oder bereitgestelltes Zertifikat.
  4. Die App installieren
    • Nach dem Signieren fragt ein Hinweis, ob die App installiert werden soll.
    • Tippen Sie auf Installieren. Das Symbol von 3105 erscheint auf dem Home Bildschirm.

Teil 2: die A330 in Aerofly FS Global installieren

Sobald 3105 installiert ist und startet, stellen Sie sicher, dass Aerofly FS Global vollständig geschlossen ist, bevor Sie fortfahren.

  1. Die A330 Datei holen
    • Laden Sie die Mobil Edition der A330 aus Ihrer Kaufbestätigung oder Ihrer Gumroad Bibliothek herunter.
    • Wichtige Prüfung: Die Datei muss die Endung .tme haben. Nicht entpacken und nicht verändern: .zip, .tmc oder .tmd Dateien lassen sich auf diesem Weg nicht installieren.
  2. Den Aerofly Ordner in 3105 finden
    • Öffnen Sie 3105.
    • Suchen Sie in der Suchleiste den Ordner mit der Aerofly Kennung: com.aerofly.aerofly-fs-g1-ios
  3. Den Ordner resource_files öffnen
    • Tippen Sie auf den Spielordner und folgen Sie dem Pfad Documents ➡️ resource_files.
    • Falls resource_files in Documents fehlt, legen Sie ihn mit dem Ordnersymbol an, genau mit diesem kleingeschriebenen Namen.
  4. Die A330 Datei importieren
    • Tippen Sie oben rechts in 3105 auf die Schaltfläche + (Plus).
    • Wählen Sie die .tme Datei der A330, um sie in den Ordner zu kopieren.
  5. Den Simulator starten
    • Schließen Sie 3105 vollständig.
    • Öffnen Sie Aerofly FS Global. Die A330-300 wird beim Start geladen und erscheint in der Flugzeugliste.

Für ein Update auf dem Mobilgerät laden Sie die neue .tme Datei herunter und ersetzen die alte auf dem gleichen Weg.
