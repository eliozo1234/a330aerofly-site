Installation

Installez l'A330-300 sur PC, Android ou iOS. Choisissez votre plateforme et suivez les étapes.

PCAerofly FS 4 · Windows AndroidAerofly FS Global iOSAerofly FS Global

PC · Aerofly FS 4

  1. Ouvrez votre email de reçu Gumroad, ou votre bibliothèque Gumroad, et téléchargez le ZIP de l'édition PC.
  2. Décompressez le : vous obtenez un dossier nommé a330.
  3. Placez ce dossier dans Documents\Aerofly FS 4\aircraft\ (créez le dossier aircraft s'il n'existe pas).
  4. Lancez Aerofly FS 4. L'A330-300 apparaît dans la liste des avions, rubrique Airliners.

Pour mettre à jour, téléchargez la dernière version depuis votre bibliothèque Gumroad et remplacez le dossier a330.

Android · Aerofly FS Global

Prérequis : le DR400. L'édition mobile prend la place du Robin DR400 dans Aerofly FS Global : vous devez donc posséder le DR400 dans l'app. Une fois le fichier .tme de l'A330 installé, le DR400 est remplacé par l'A330-300. Supprimez le fichier .tme de l'A330 pour retrouver le DR400.

L'édition mobile est un seul fichier .tme. Téléchargez le depuis votre email de reçu ou votre bibliothèque Gumroad directement sur votre téléphone ou votre tablette, sans le décompresser ni le renommer.

Sur Android, l'installation prend quelques minutes avec un gestionnaire de fichiers. Le tutoriel pas à pas de ZK Aviation montre chaque écran.

Ouvrir le tutoriel Android

Installez le fichier .tme de l'A330 exactement comme les mods du tutoriel.

iOS · Aerofly FS Global

Sur iOS, les add ons se copient dans les données de l'app Aerofly FS Global avec 3105, un explorateur gratuit des données d'apps installé en dehors de l'App Store. Deux parties : installer 3105 une fois, puis copier le fichier de l'A330.

Prérequis : le DR400. L'édition mobile prend la place du Robin DR400 dans Aerofly FS Global : vous devez donc posséder le DR400 dans l'app. Une fois le fichier .tme de l'A330 installé, le DR400 est remplacé par l'A330-300. Supprimez le fichier .tme de l'A330 pour retrouver le DR400.

3105, E-Sign et KSign sont des outils tiers, fournis ni par Apple, ni par IPACS, ni par A330 Aerofly Development. Vous les installez sous votre responsabilité.

Partie 1 : installer l'app 3105

3105 est un explorateur natif des données d'apps iOS, absent de l'App Store : il faut donc l'installer à part (sideload) avec un outil de signature sur l'appareil. E-Sign et KSign sont les plus utilisés pour cela.

  1. Téléchargez le fichier IPA de 3105
    • Ouvrez Safari et allez sur le dépôt GitHub officiel YangJiiii/3105.
    • Ouvrez la section Releases, faites défiler et téléchargez le fichier 3105-unsigned.ipa sur votre appareil.
  2. Ouvrez votre outil de signature (E-Sign, KSign)
    • Lancez l'app de signature.
    • Si vous n'en avez pas encore, installez d'abord un outil de signature via Safari, puis faites confiance à son certificat d'entreprise dans les Réglages d'iOS.
  3. Importez et signez l'IPA
    • Dans l'app de signature, touchez l'icône + (Plus) ou Importer.
    • Choisissez 3105-unsigned.ipa dans l'app Fichiers.
    • Touchez le fichier importé, choisissez Signature ou Sign App, puis votre certificat actif ou fourni.
  4. Installez l'app
    • À la fin de la signature, une fenêtre propose d'installer l'app.
    • Touchez Installer. L'icône de 3105 apparaît sur l'écran d'accueil.

Partie 2 : installer l'A330 dans Aerofly FS Global

Une fois 3105 installé et ouvert, vérifiez qu'Aerofly FS Global est complètement fermé avant de continuer.

  1. Récupérez le fichier de l'A330
    • Téléchargez l'édition mobile de l'A330 depuis votre email de reçu ou votre bibliothèque Gumroad.
    • Vérification essentielle : le fichier doit avoir l'extension .tme. Ne le décompressez pas et ne le modifiez pas : les fichiers .zip, .tmc ou .tmd ne s'installent pas par cette méthode.
  2. Trouvez le dossier d'Aerofly dans 3105
    • Ouvrez 3105.
    • Dans la barre de recherche, cherchez le dossier de l'identifiant d'Aerofly : com.aerofly.aerofly-fs-g1-ios
  3. Ouvrez le dossier des ressources
    • Touchez le dossier du jeu et suivez le chemin Documents ➡️ resource_files.
    • Si resource_files n'existe pas dans Documents, créez le avec l'icône de dossier, exactement sous ce nom en minuscules.
  4. Importez le fichier de l'A330
    • Touchez le bouton + (Plus) en haut à droite de 3105.
    • Choisissez le fichier .tme de l'A330 pour le copier dans le dossier.
  5. Lancez le simulateur
    • Fermez complètement 3105.
    • Ouvrez Aerofly FS Global. L'A330-300 est chargé au démarrage et apparaît dans la liste des avions.

Pour mettre à jour sur mobile, téléchargez le nouveau fichier .tme et remplacez l'ancien de la même façon.
