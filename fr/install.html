Installation

Installez l'A330-300 sur PC, Android ou iOS. Choisissez votre plateforme et suivez les étapes.

PCAerofly FS 4 · Windows AndroidAerofly FS Global iOSAerofly FS Global

PC · Aerofly FS 4

  1. Ouvrez votre email de reçu Gumroad, ou votre bibliothèque Gumroad, et téléchargez le ZIP de l'édition PC.
  2. Décompressez le : vous obtenez un dossier nommé a330.
  3. Placez ce dossier dans Documents\Aerofly FS 4\aircraft\ (créez le dossier aircraft s'il n'existe pas).
  4. Lancez Aerofly FS 4. L'A330-300 apparaît dans la liste des avions, rubrique Airliners.

Pour mettre à jour, téléchargez la dernière version depuis votre bibliothèque Gumroad et remplacez le dossier a330.

Android · Aerofly FS Global

Prérequis : le DR400. L'édition mobile prend la place du Robin DR400 dans Aerofly FS Global : vous devez donc posséder le DR400 dans l'app. Une fois le fichier .tme de l'A330 installé, le DR400 est remplacé par l'A330-300. Supprimez le fichier .tme de l'A330 pour retrouver le DR400. Le DR400 coûte 0,99 $ dans l'app si vous ne l'avez pas encore.

L'édition mobile est un seul fichier .tme. Téléchargez le depuis votre email de reçu ou votre bibliothèque Gumroad directement sur votre téléphone ou votre tablette, sans le décompresser ni le renommer.

Sur Android, l'installation prend quelques minutes avec un gestionnaire de fichiers. Le tutoriel pas à pas de ZK Aviation montre chaque écran.

Ouvrir le tutoriel Android

Installez le fichier .tme de l'A330 exactement comme les mods du tutoriel.

iOS · Aerofly FS Global

Sur iOS, le fichier de l'A330 se copie dans les données de l'app Aerofly FS Global avec WQ Files, un explorateur de fichiers gratuit installé en dehors de l'App Store. Les outils s'installent une seule fois ; ensuite, seule la dernière partie sert à mettre à jour l'A330.

Compatible avec la toute dernière version d'iOS. Cette méthode fonctionne sur iOS et iPadOS 27.0 à 27.2.1, la dernière version publique en novembre 2026, directement sur l'appareil et sans ordinateur. Elle fonctionne aussi de 26.0 à 26.7.2, où SideInstaller demande un fichier d'appairage créé une fois sur un ordinateur. Elle ne fonctionne pas sur iOS 27.3 bêta 2 et versions suivantes : installez l'A330 avant de passer à iOS 27.3. iOS 18 et les versions antérieures ne sont pas pris en charge.

Prérequis : le DR400. L'édition mobile prend la place du Robin DR400 dans Aerofly FS Global : vous devez donc posséder le DR400 dans l'app. Une fois le fichier .tme de l'A330 installé, le DR400 est remplacé par l'A330-300. Supprimez le fichier .tme de l'A330 pour retrouver le DR400. Le DR400 coûte 0,99 $ dans l'app si vous ne l'avez pas encore.

SideInstaller, Skibidi Tech, LocalDevVPN et WQ Files sont des outils tiers, fournis ni par Apple, ni par IPACS, ni par A330 Aerofly Development. Vous les installez sous votre responsabilité. Lisez d'abord l'avertissement iOS en bas de cette page.

Partie 1 : préparer l'iPhone ou l'iPad

  1. Activez le mode développeur
    • Ouvrez Réglages, Confidentialité et sécurité, Mode développeur.
    • Activez le et confirmez le redémarrage.
    • Après le redémarrage, confirmez de nouveau et saisissez votre code.

Partie 2 : installer SideInstaller

  1. Téléchargez le profil Skibidi Tech
    • Ouvrez skibiditech.co dans Safari.
    • Descendez jusqu'à Download profile, touchez le, puis touchez Autoriser.
  2. Installez le profil
    • Ouvrez Réglages et touchez Profil téléchargé.
    • Touchez Installer en haut à droite et confirmez.
  3. Téléchargez SideInstaller
    • Ouvrez l'app Skibidi Tech depuis l'écran d'accueil.
    • Dans l'onglet Others, touchez Install à côté de SideInstaller et attendez la fin de l'installation.
  4. Faites confiance à l'app
    • Ouvrez Réglages, Général, VPN et gestion de l'appareil.
    • Touchez le certificat de l'app (Chengdu Railway Bureau dans le guide), puis Faire confiance.
    • Touchez Autoriser et redémarrer. L'appareil peut redémarrer plusieurs fois : ne l'éteignez pas vous même.
  5. Configurez SideInstaller
    • Ouvrez SideInstaller, accordez les autorisations demandées, acceptez les conditions et touchez Start.
    • Quand l'app demande si elle vient de sideinstaller.net, le guide répond Oui.
    • Connectez vous avec un compte Apple. Nous recommandons un compte secondaire plutôt que votre compte principal.

Partie 3 : installer WQ Files

  1. Installez LocalDevVPN
    • Installez LocalDevVPN depuis l'App Store et ouvrez le.
    • Touchez Next jusqu'à l'écran principal, puis Connect.
    • Autorisez la configuration VPN. Laissez le connecté jusqu'à la fin de la partie 3.
  2. Téléchargez WQ Files
    • Ouvrez la page officielle de WQ Files sur GitHub.
    • Descendez jusqu'à Install with AltStore or SideStore et touchez Download .ipa.
  3. Importez le dans SideInstaller
    • Dans la section Install de SideInstaller, touchez le menu SideStore et choisissez Custom .ipa.
    • Touchez Import .ipa, choisissez WQFiles.ipa, puis touchez Install Custom .ipa.
  4. Appairez l'appareil
    • Ouvrez Réglages, Confidentialité et sécurité, Mode développeur.
    • Touchez Pair with SideInstaller, puis Jumeler, et saisissez le code à 6 chiffres affiché dans SideInstaller.
  5. Terminez l'installation
    • Revenez dans SideInstaller, autorisez votre compte Apple et saisissez le code de vérification si besoin.
    • Attendez la fin de l'installation.
  6. Faites confiance à WQ Files
    • Ouvrez Réglages, Général, VPN et gestion de l'appareil.
    • Sous App de développeur, touchez votre compte Apple, puis Faire confiance.

Partie 4 : installer l'A330 dans Aerofly FS Global

  1. Récupérez le fichier de l'A330
    • Téléchargez l'édition mobile de l'A330 depuis votre email de reçu ou votre bibliothèque Gumroad.
    • Vérification essentielle : le fichier doit avoir l'extension .tme. Ne le décompressez pas, ne le renommez pas et ne le modifiez pas.
    • Fermez complètement Aerofly FS Global.
  2. Ouvrez le dossier d'Aerofly dans WQ Files
    • Ouvrez WQ Files et accordez les autorisations demandées.
    • Touchez Apps et attendez la fin de l'analyse, puis touchez Aerofly FS et Open Data Folder.
    • Suivez le chemin Documents ➡️ resource_files. Si resource_files n'existe pas, créez le, exactement sous ce nom en minuscules.
  3. Importez le fichier de l'A330
    • Touchez les trois points en haut à droite, puis Import Files.
    • Choisissez le fichier .tme de l'A330 et attendez la fin de l'import.
    • Ne déplacez et ne supprimez pas les autres fichiers.
  4. Lancez le simulateur
    • Fermez WQ Files et ouvrez Aerofly FS Global. L'A330-300 apparaît dans la liste des avions.
    • Sinon, forcez la fermeture d'Aerofly FS Global et ouvrez le de nouveau.

Pour mettre à jour sur mobile, téléchargez le nouveau fichier .tme et remplacez l'ancien de la même façon.
