Support

Installation, premier vol et aide. La plupart des questions trouvent leur réponse ici ; pour le reste, écrivez nous.

Installation, PC (Aerofly FS 4)

  1. Téléchargez le ZIP depuis la page de votre commande Lemon Squeezy.
  2. Décompressez le : vous obtenez un dossier nommé a330.
  3. Placez ce dossier dans Documents\Aerofly FS 4\aircraft\ (créez le dossier aircraft s'il n'existe pas).
  4. Lancez Aerofly FS 4. L'A330-300 apparaît dans la liste des avions, rubrique Airliners.

Installation, mobile (Aerofly FS)

  1. Téléchargez le paquet mobile depuis la page de votre commande Lemon Squeezy sur votre téléphone ou tablette.
  2. Ouvrez Aerofly FS, allez dans Réglages → Avions additionnels et choisissez Importer.
  3. Sélectionnez le fichier téléchargé. L'avion s'installe dans l'application et apparaît dans la liste.
  4. Les livrées se choisissent dans le menu de livrées de l'avion, comme pour un avion d'origine.

Premier vol

Partez de la position Décollage pour un avion prêt à voler, ou de Cold and Dark pour la mise en route complète. Saisissez vos masses et votre indice de coût sur la page INIT B du MCDU, vos vitesses et vos volets sur PERF TAKE OFF : le trim de décollage se calcule à partir du centrage que vous entrez. Surveillez l'ECAM : si la configuration est mauvaise, il vous le dira avant l'alignement.

Dépannage

  • L'avion n'est pas dans la liste (PC) : vérifiez que le dossier est exactement Documents\Aerofly FS 4\aircraft\a330 et contient a330.tmc.
  • Une livrée manque : les livrées se choisissent dans le menu de livrées de l'avion ; vérifiez que vous avez installé la dernière version du paquet.
  • Pas de son moteur après l'installation : relancez le simulateur une fois.
  • Mises à jour : téléchargez la dernière version depuis le même lien Lemon Squeezy et remplacez le dossier a330.
