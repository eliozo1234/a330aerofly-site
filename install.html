Installation

Install the A330-300 on PC, Android or iOS. Choose your platform and follow the steps.

PCAerofly FS 4 · Windows AndroidAerofly FS Global iOSAerofly FS Global

PC · Aerofly FS 4

  1. Open your Gumroad receipt email, or your Gumroad library, and download the PC edition ZIP.
  2. Unzip it. You get a folder named a330.
  3. Move that folder into Documents\Aerofly FS 4\aircraft\ (create the aircraft folder if it does not exist).
  4. Start Aerofly FS 4. The A330-300 appears in the aircraft list under Airliners.

To update, download the latest version from your Gumroad library and replace the a330 folder.

Android · Aerofly FS Global

Required: the DR400. The mobile edition takes the place of the Robin DR400 in Aerofly FS Global, so you must own the DR400 in the app. Once the A330 .tme file is installed, the DR400 is replaced by the A330-300. Delete the A330 .tme file to get the DR400 back.

The mobile edition is a single .tme file. Download it from your Gumroad receipt email or library directly to your phone or tablet, and do not unzip or rename it.

On Android, installation takes a few minutes with a file manager. The step by step tutorial by ZK Aviation shows every screen.

Open the Android tutorial

Install the A330 .tme file exactly like the mods in the tutorial.

iOS · Aerofly FS Global

On iOS, add ons are copied into the Aerofly FS Global app data with 3105, a free app data browser installed outside the App Store. There are two parts: installing 3105 once, then copying the A330 file.

Required: the DR400. The mobile edition takes the place of the Robin DR400 in Aerofly FS Global, so you must own the DR400 in the app. Once the A330 .tme file is installed, the DR400 is replaced by the A330-300. Delete the A330 .tme file to get the DR400 back.

3105, E-Sign and KSign are third party tools, provided neither by Apple, nor by IPACS, nor by A330 Aerofly Development. You install them at your own risk.

Part 1: install the 3105 app

3105 is a native iOS app data browser that is not available on the App Store, so it has to be sideloaded with an on device signing tool. E-Sign and KSign are the most common tools for this.

  1. Download the 3105 IPA file
    • Open Safari and go to the official YangJiiii/3105 GitHub repository.
    • Open the Releases section, scroll down and download the 3105-unsigned.ipa file to your device.
  2. Open your signing tool (E-Sign, KSign)
    • Launch the signing app.
    • If you do not have one yet, install an on device signing tool first through Safari, then trust its enterprise certificate in the iOS Settings.
  3. Import and sign the IPA
    • In the signing app, tap the + (Plus) or Import icon.
    • Select 3105-unsigned.ipa in the Files app.
    • Tap the imported file, choose Signature or Sign App, then pick your active or provided certificate.
  4. Install the app
    • When signing finishes, a prompt asks you to install the app.
    • Tap Install. The 3105 icon appears on your home screen.

Part 2: install the A330 in Aerofly FS Global

Once 3105 is installed and opens, make sure Aerofly FS Global is completely closed before going further.

  1. Get the A330 file
    • Download the A330 mobile edition from your Gumroad receipt email or library.
    • Critical check: the file must have the .tme extension. Do not unzip or modify it: .zip, .tmc or .tmd files cannot be installed this way.
  2. Find the Aerofly folder in 3105
    • Open 3105.
    • In the search bar, look for the Aerofly identifier folder: com.aerofly.aerofly-fs-g1-ios
  3. Open the resource files folder
    • Tap the game folder and follow the path Documents ➡️ resource_files.
    • If resource_files does not exist inside Documents, create it with the folder icon, using exactly that lowercase name.
  4. Import the A330 file
    • Tap the + (Plus) button at the top right of 3105.
    • Select the A330 .tme file to copy it into the folder.
  5. Start the simulator
    • Close 3105 completely.
    • Open Aerofly FS Global. The A330-300 is loaded at startup and appears in the aircraft list.

To update on mobile, download the new .tme file and replace the old one the same way.
