Installation

Install the A330-300 on PC, Android or iOS. Choose your platform and follow the steps.

PCAerofly FS 4 · Windows AndroidAerofly FS Global iOSAerofly FS Global

PC · Aerofly FS 4

  1. Open your Gumroad receipt email, or your Gumroad library, and download the PC edition ZIP.
  2. Unzip it. You get a folder named a330.
  3. Move that folder into Documents\Aerofly FS 4\aircraft\ (create the aircraft folder if it does not exist).
  4. Start Aerofly FS 4. The A330-300 appears in the aircraft list under Airliners.

To update, download the latest version from your Gumroad library and replace the a330 folder.

Android · Aerofly FS Global

Required: the DR400. The mobile edition takes the place of the Robin DR400 in Aerofly FS Global, so you must own the DR400 in the app. Once the A330 .tme file is installed, the DR400 is replaced by the A330-300. Delete the A330 .tme file to get the DR400 back. The DR400 costs $0.99 in the app if you don't own it yet.

The mobile edition is a single .tme file. Download it from your Gumroad receipt email or library directly to your phone or tablet, and do not unzip or rename it.

On Android, installation takes a few minutes with a file manager. The step by step tutorial by ZK Aviation shows every screen.

Open the Android tutorial

Install the A330 .tme file exactly like the mods in the tutorial.

iOS · Aerofly FS Global

On iOS, the A330 file is copied into the Aerofly FS Global app data with WQ Files, a free file browser installed outside the App Store. You install the tools once, then only the last part is needed to update the A330.

Compatible with the latest iOS. This method works on iOS and iPadOS 27.0 to 27.2.1, the latest public version in November 2026, directly on the device and without a computer. It also works on 26.0 to 26.7.2, where SideInstaller needs a pairing file made once on a computer. It does not work on iOS 27.3 beta 2 and later, so install the A330 before updating to iOS 27.3. iOS 18 and earlier are not supported.

Required: the DR400. The mobile edition takes the place of the Robin DR400 in Aerofly FS Global, so you must own the DR400 in the app. Once the A330 .tme file is installed, the DR400 is replaced by the A330-300. Delete the A330 .tme file to get the DR400 back. The DR400 costs $0.99 in the app if you don't own it yet.

Part 1: prepare the iPhone or iPad

  1. Turn on Developer Mode
    • Open Settings, Privacy & Security, Developer Mode.
    • Turn it on and confirm the restart.
    • After the restart, confirm again and enter your passcode.

Part 2: install SideInstaller

  1. Download the Skibidi Tech profile
    • Open skibiditech.co in Safari.
    • Scroll to Download profile, tap it, then tap Allow.
  2. Install the profile
    • Open Settings and tap Profile Downloaded.
    • Tap Install at the top right and confirm.
  3. Download SideInstaller
    • Open the Skibidi Tech app from the home screen.
    • In the Others tab, tap Install next to SideInstaller and wait for the installation to end.
  4. Trust the app
    • Open Settings, General, VPN & Device Management.
    • Tap the certificate of the app (Chengdu Railway Bureau in the guide), then Trust.
    • Tap Allow & Restart. The device may restart more than once: do not turn it off yourself.
  5. Set up SideInstaller
    • Open SideInstaller, allow the requested permissions, accept the terms and tap Start.
    • When the app asks whether it comes from sideinstaller.net, the guide answers Yes.
    • Sign in with an Apple Account. We recommend a secondary account rather than your main one.

Part 3: install WQ Files

  1. Install LocalDevVPN
    • Install LocalDevVPN from the App Store and open it.
    • Tap Next until the main screen, then Connect.
    • Allow the VPN configuration. Keep it connected until Part 3 is finished.
  2. Download WQ Files
    • Open the official WQ Files page on GitHub.
    • Scroll to Install with AltStore or SideStore and tap Download .ipa.
  3. Import it in SideInstaller
    • In the Install section of SideInstaller, tap the SideStore menu and choose Custom .ipa.
    • Tap Import .ipa, choose WQFiles.ipa, then tap Install Custom .ipa.
  4. Pair the device
    • Open Settings, Privacy & Security, Developer Mode.
    • Tap Pair with SideInstaller, then Pair, and enter the 6 digit code shown in SideInstaller.
  5. Finish the installation
    • Go back to SideInstaller, authorize your Apple Account and enter the verification code if asked.
    • Wait until the installation ends.
  6. Trust WQ Files
    • Open Settings, General, VPN & Device Management.
    • Under Developer App, tap your Apple Account, then Trust.

Part 4: install the A330 in Aerofly FS Global

  1. Get the A330 file
    • Download the A330 mobile edition from your Gumroad receipt email or library.
    • Critical check: the file must have the .tme extension. Do not unzip, rename or modify it.
    • Close Aerofly FS Global completely.
  2. Open the Aerofly folder in WQ Files
    • Open WQ Files and allow the requested permissions.
    • Tap Apps and wait for the scan to end, then tap Aerofly FS and Open Data Folder.
    • Follow the path Documents ➡️ resource_files. If resource_files does not exist, create it, using exactly that lowercase name.
  3. Import the A330 file
    • Tap the three dots at the top right, then Import Files.
    • Choose the A330 .tme file and wait for the import to end.
    • Do not move or delete the other files.
  4. Start the simulator
    • Close WQ Files and open Aerofly FS Global. The A330-300 appears in the aircraft list.
    • If it does not, force close Aerofly FS Global and open it again.

To update on mobile, download the new .tme file and replace the old one the same way.
