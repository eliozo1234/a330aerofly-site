安装

在 PC、Android 或 iOS 上安装 A330-300。选择你的平台，按步骤操作。

PCAerofly FS 4 · Windows AndroidAerofly FS Global iOSAerofly FS Global

PC · Aerofly FS 4

  1. 打开 Gumroad 收据邮件或你的 Gumroad 资料库，下载 PC 版 ZIP 文件。
  2. 解压后得到一个名为 a330 的文件夹。
  3. 将该文件夹移动到 文档\Aerofly FS 4\aircraft\（如果没有 aircraft 文件夹，请先创建）。
  4. 启动 Aerofly FS 4。A330-300 会出现在机型列表的 Airliners 分类中。

更新时，从 Gumroad 资料库下载最新版本，替换 a330 文件夹即可。

Android · Aerofly FS Global

前提条件：DR400。 移动版会占用 Aerofly FS Global 中 Robin DR400 的位置，因此你必须在应用中拥有 DR400。安装 A330 的 .tme 文件后，DR400 会被 A330-300 替换。删除 A330 的 .tme 文件即可恢复 DR400。若尚未拥有 DR400，应用内售价 0.99 美元。

移动版是一个单独的 .tme 文件。请从 Gumroad 收据邮件或资料库直接下载到手机或平板，不要解压，也不要改名。

在 Android 上，用文件管理器几分钟即可完成安装。ZK Aviation 的分步教程展示了每一个界面。

打开 Android 教程

按照教程中安装模组的方式安装 A330 的 .tme 文件即可。

iOS · Aerofly FS Global

在 iOS 上，需要用 WQ Files 把 A330 文件复制到 Aerofly FS Global 的应用数据中。WQ Files 是一款免费的文件浏览器，需在 App Store 之外安装。工具只需安装一次，之后更新 A330 只需要最后一部分。

兼容最新版 iOS。此方法适用于 iOS 和 iPadOS 27.0 至 27.2.1（2026 年 11 月的最新公开版本），直接在设备上完成，无需电脑。也适用于 26.0 至 26.7.2，但 SideInstaller 需要先在电脑上生成一次配对文件。不适用于 iOS 27.3 beta 2 及更高版本：请在升级到 iOS 27.3 之前安装 A330。不支持 iOS 18 及更早版本。

前提条件：DR400。 移动版会占用 Aerofly FS Global 中 Robin DR400 的位置，因此你必须在应用中拥有 DR400。安装 A330 的 .tme 文件后，DR400 会被 A330-300 替换。删除 A330 的 .tme 文件即可恢复 DR400。若尚未拥有 DR400，应用内售价 0.99 美元。

SideInstaller、Skibidi Tech、LocalDevVPN 和 WQ Files 均为第三方工具，并非由 Apple、IPACS 或 A330 Aerofly Development 提供。安装风险由你自行承担。请先阅读本页底部的 iOS 免责声明。

由 Alvessz 制作的英文图解教程（34 页，1.9 MB）。

第 1 部分：准备 iPhone 或 iPad

  1. 开启开发者模式
    • 打开“设置”，进入“隐私与安全性”，再进入“开发者模式”。
    • 开启并确认重启。
    • 重启后再次确认，并输入锁屏密码。

第 2 部分：安装 SideInstaller

  1. 下载 Skibidi Tech 描述文件
    • 在 Safari 中打开 skibiditech.co。
    • 向下滚动到 Download profile，点击它，然后点击允许。
  2. 安装描述文件
    • 打开“设置”，点击“已下载描述文件”。
    • 点击右上角的安装并确认。
  3. 下载 SideInstaller
    • 从主屏幕打开 Skibidi Tech 应用。
    • 在 Others 标签页中，点击 SideInstaller 旁的 Install，等待安装完成。
  4. 信任该应用
    • 打开“设置”，进入“通用”，再进入“VPN与设备管理”。
    • 点击该应用的证书（教程中为 Chengdu Railway Bureau），然后点击信任。
    • 点击允许并重新启动。设备可能会多次重启：请勿自行关机。
  5. 设置 SideInstaller
    • 打开 SideInstaller，允许所需权限，接受条款并点击 Start。
    • 当应用询问它是否来自 sideinstaller.net 时，教程的回答为“是”。
    • 登录 Apple 账户。建议使用备用账户，而不是主账户。

第 3 部分：安装 WQ Files

  1. 安装 LocalDevVPN
    • 从 App Store 安装 LocalDevVPN 并打开。
    • 点击 Next 直到主界面，然后点击 Connect。
    • 允许添加 VPN 配置。在第 3 部分完成之前保持连接。
  2. 下载 WQ Files
    • 打开 GitHub 上的 WQ Files 官方页面。
    • 向下滚动到 Install with AltStore or SideStore，点击 Download .ipa。
  3. 在 SideInstaller 中导入
    • 在 SideInstaller 的 Install 部分，点击 SideStore 菜单并选择 Custom .ipa。
    • 点击 Import .ipa，选择 WQFiles.ipa，然后点击 Install Custom .ipa。
  4. 配对设备
    • 打开“设置”，进入“隐私与安全性”，再进入“开发者模式”。
    • 点击 Pair with SideInstaller，再点击配对，输入 SideInstaller 显示的 6 位数字。
  5. 完成安装
    • 返回 SideInstaller，授权你的 Apple 账户，如有需要请输入验证码。
    • 等待安装完成。
  6. 信任 WQ Files
    • 打开“设置”，进入“通用”，再进入“VPN与设备管理”。
    • 在开发者 App 下点击你的 Apple 账户，然后点击信任。

第 4 部分：在 Aerofly FS Global 中安装 A330

  1. 获取 A330 文件
    • 从 Gumroad 收据邮件或资料库下载 A330 移动版。
    • 关键检查：文件扩展名必须是 .tme。不要解压、重命名或修改。
    • 完全关闭 Aerofly FS Global。
  2. 在 WQ Files 中打开 Aerofly 文件夹
    • 打开 WQ Files 并允许所需权限。
    • 点击 Apps，等待扫描完成，然后点击 Aerofly FS 和 Open Data Folder。
    • 按路径进入 Documents ➡️ resource_files。如果没有 resource_files，请手动创建，名称必须完全一致且为小写。
  3. 导入 A330 文件
    • 点击右上角的三个点，然后点击 Import Files。
    • 选择 A330 的 .tme 文件，等待导入完成。
    • 不要移动或删除其他文件。
  4. 启动模拟器
    • 关闭 WQ Files 并打开 Aerofly FS Global，A330-300 会出现在机型列表中。
    • 如果没有出现，请强制关闭 Aerofly FS Global 后重新打开。

在移动端更新时，下载新的 .tme 文件，用同样的方式替换旧文件。
