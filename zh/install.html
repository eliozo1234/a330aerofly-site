安装

在 PC、Android 或 iOS 上安装 A330-300。选择你的平台，按步骤操作。

PCAerofly FS 4 · Windows AndroidAerofly FS Global iOSAerofly FS Global

PC · Aerofly FS 4

  1. 打开 Gumroad 收据邮件或你的 Gumroad 资料库，下载 PC 版 ZIP 文件。
  2. 解压后得到一个名为 a330 的文件夹。
  3. 将该文件夹移动到 文档\Aerofly FS 4\aircraft\（如果没有 aircraft 文件夹，请先创建）。
  4. 启动 Aerofly FS 4。A330-300 会出现在机型列表的 Airliners 分类中。

更新时，从 Gumroad 资料库下载最新版本，替换 a330 文件夹即可。

Android · Aerofly FS Global

移动版是一个单独的 .tme 文件。请从 Gumroad 收据邮件或资料库直接下载到手机或平板，不要解压，也不要改名。

在 Android 上，用文件管理器几分钟即可完成安装。ZK Aviation 的分步教程展示了每一个界面。

打开 Android 教程

按照教程中安装模组的方式安装 A330 的 .tme 文件即可。

iOS · Aerofly FS Global

在 iOS 上，需要用 3105 把附加内容复制到 Aerofly FS Global 的应用数据中。3105 是一款免费的应用数据浏览器，需在 App Store 之外安装。共分两部分：先安装一次 3105，再复制 A330 文件。

3105、E-Sign 和 KSign 均为第三方工具，并非由 Apple、IPACS 或 A330 Aerofly Development 提供。安装风险由你自行承担。

第一部分：安装 3105 应用

3105 是一款原生的 iOS 应用数据浏览器，App Store 中没有，因此需要借助设备端签名工具侧载安装。最常用的是 E-Sign 或 KSign。

  1. 下载 3105 的 IPA 文件
    • 打开 Safari，进入官方 YangJiiii/3105 GitHub 仓库。
    • 打开 Releases 部分，向下滚动，将 3105-unsigned.ipa 文件下载到设备上。
  2. 打开签名工具（E-Sign、KSign）
    • 启动签名应用。
    • 如果还没有签名工具，请先通过 Safari 安装一个，并在 iOS 设置中信任其企业证书。
  3. 导入并签名 IPA
    • 在签名应用中点击 +（加号）或导入图标。
    • 在“文件”应用中选择 3105-unsigned.ipa。
    • 点击导入的文件，选择 Signature 或 Sign App，再选择你当前可用或提供的证书。
  4. 安装应用
    • 签名完成后，会弹出安装提示。
    • 点击安装，3105 图标会出现在主屏幕上。

第二部分：在 Aerofly FS Global 中安装 A330

3105 安装并能打开后，继续之前请确认 Aerofly FS Global 已完全关闭。

  1. 获取 A330 文件
    • 从 Gumroad 收据邮件或资料库下载 A330 移动版。
    • 关键检查：文件扩展名必须是 .tme。不要解压或修改：.zip、.tmc 或 .tmd 文件无法用此方法安装。
  2. 在 3105 中找到 Aerofly 文件夹
    • 打开 3105。
    • 在搜索栏中查找 Aerofly 的标识文件夹：com.aerofly.aerofly-fs-g1-ios
  3. 打开资源文件夹
    • 点击游戏文件夹，按路径进入 Documents ➡️ resource_files。
    • 如果 Documents 中没有 resource_files，请用新建文件夹图标手动创建，名称必须完全一致且为小写。
  4. 导入 A330 文件
    • 点击 3105 右上角的 +（加号）按钮。
    • 选择 A330 的 .tme 文件，将其复制到该文件夹。
  5. 启动模拟器
    • 完全关闭 3105。
    • 打开 Aerofly FS Global，A330-300 会在启动时加载并出现在机型列表中。

在移动端更新时，下载新的 .tme 文件，用同样的方式替换旧文件。
